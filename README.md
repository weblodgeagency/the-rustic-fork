# The Rustic Fork — Farm-to-Table Restaurant, Denver CO

A single-page website for a farm-to-table restaurant in Denver, Colorado — seasonal menu with prices, guest reviews, opening hours, and table booking.

**Live site:** https://weblodgeagency.github.io/the-rustic-fork/

Built with plain HTML and CSS (no framework): sticky navigation, hero, seasonal menu, reviews, hours and location.

Website designed & built by [Weblodge Agency](https://weblodge.agency).
